# Paradise Nursery

Welcome to Paradise Nursery!

Paradise Nursery is an online plant shop where customers can explore and purchase beautiful houseplants.

## Project Description

This application allows users to:
- Browse houseplants by category.
- View plant images, names, descriptions, and prices.
- Add plants to a shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- View the total shopping cart cost.

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Router

## Project Goal

To create a user-friendly online shopping experience for plant lovers.
